# HMIC LLC

Independent work in AI evaluation, provenance, agent workflows, and generated media. TJ Jung builds the systems and publishes selected code, data, methods, and finished artifacts here and at [hmic.dev](https://hmic.dev/).

## Public repositories

- [ALCOA RubberStamp](https://github.com/HMIC-LLC/alcoa-rubberstamp) is a Python reference tool for making and verifying deterministic file-set commitments. It includes tests and a fixed example. It does not certify a record's truth or provide regulatory validation.
- [Programmed Interface Compression](https://github.com/HMIC-LLC/programmed-interface-compression) contains a locked definition, recognition criteria, examples, and citation information. Its publication does not imply a reuse license.

## Work you can inspect

- [MTT48 grader audit](https://hmic.dev/articles/grader-read-unit-id-as-temperature/): an evaluation post-mortem with a [public V1 dataset and replay materials](https://huggingface.co/datasets/tj-jung/mtt48-v1-grader-audit).
- [Patch Tuesday Apocalypse](https://hmic.dev/proof/patch-tuesday-apocalypse/): a finished music video and an account of the image-to-video workflow behind it.
- [HMIC arcade](https://hmic.dev/games/): playable work in progress and experiments.

Each repository states its own license, scope, and limitations. Public examples are selected for disclosure; the private SubC operating workspace is not a public source repository.
